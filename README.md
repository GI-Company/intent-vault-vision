# INTENT Vault Vision

Native Android AI camera and private assistant. Uses CameraX, bundled ML Kit smile detection and Google's EmbeddingGemma 2 Text+Vision for local semantic matching.

**Source in progress:** the model is bundled into release builds by CI; source checkouts intentionally do not commit large binary weights. EmbeddingGemma is an embedder, not a chatbot. See `docs/ARCHITECTURE.md`.
